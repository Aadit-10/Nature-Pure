# Nature Pure Supercritical Extracts - Website Rebuild

A complete, pixel-perfect, standalone rebuild of the official **Nature Pure Extracts** website ([https://naturepureextracts.com/](https://naturepureextracts.com/)), including all 42 pages, 1,040+ high-resolution images, stylesheets, fonts, interactive elements, forms, and responsive navigation.

---

## 🌟 Highlights & What Has Been Rebuilt

- **100% Complete Content**: Every single page, paragraph, heading, card, table, specification, and footer item has been faithfully extracted and reconstructed.
- **All Assets & Media (1,040+ Images)**: High-resolution brand logos, product banners, lab photography, manufacturing certifications, background patterns, and icons are downloaded locally under `wp-content/uploads/` and preserved.
- **42 Complete Pages & Sub-routes**: Full directory support for standard clean URLs (`/about-us/`, `/nature-harvest/`, `/rd/`, etc.) and flat file fallback (`about-us.html`, `rd.html`, etc.).
- **Typography & Styling**: Google Fonts (Poppins, Montserrat, Roboto, Roboto Slab) and Astra/Elementor responsive design systems for desktop, tablet, and mobile breakpoints.
- **Interactive Enhancements**:
  - **Contact & Inquiry Forms**: Intercepts form submissions across all pages with user feedback notifications ("Thank you! Your message has been received.") and input resets.
  - **Floating WhatsApp Widget**: Direct one-click connection to official Nature Pure WhatsApp (`+91 95678 89001`).
  - **Mobile Hamburger Navigation**: Fully functional drawer menu toggle for smartphone and tablet viewports.
  - **Embedded Google Maps**: Interactive map showing Nature Pure Supercritical Extracts facility in Kinfra Industrial Park, Thiruvalla, Kerala.
- **Zero External CMS Dependencies**: No WordPress PHP server, database, or external LiteSpeed dependencies required. Fully static and ultra-fast.

## 🚀 How to Run Locally

### Option 1: Using the Included Node.js Server (Recommended)

Run:
```bash
npm start
```
or:
```bash
node server.js
```

Open your browser and navigate to:
```
http://localhost:8080/
```

### Option 2: Using Any Static HTTP Server

You can also serve this project with any HTTP server:
```bash
# Using npx serve
npx serve .

# Using Python
python -m http.server 8080

# Using live-server
npx live-server .
```

## 🚢 Deployment

Because the website consists of standard static HTML, CSS, JavaScript, and images, it can be deployed directly to:
- **Vercel**: Run `vercel` or link your Git repository.
- **Netlify**: Drag and drop the folder into the Netlify dashboard or push to GitHub.
- **GitHub Pages**: Push the repository to GitHub and enable GitHub Pages in repository settings.
- **Apache / Nginx / Caddy**: Point the web root to this directory.
